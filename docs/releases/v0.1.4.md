## 新增

- **应用内更新弹窗**。检查到新正式版时显示版本和更新日志。下载过程中显示进度条、已下载大小和可用的百分比，下载完成后显示校验及安装状态。
- **项目源码链接**。设置页底部新增 GitHub 仓库入口。

## 调整与修复

- **封面裁切**。修复长按拖动时误选中图片的问题。拖动右下角圆点调整大小，按住 Alt 时围绕中心缩放。悬停在圆点上会提示快捷键，裁切比例保持 1:1。
- **试听**。移除播放按钮下方的加载文案，播放按钮仍会显示加载动画。
- **音频前偏移**。从 0 点到首拍的拍数在未对齐时保留小数，对齐后直接显示选中的整数拍位。括号里的红绿数值仍以秒表示实际增减量。
