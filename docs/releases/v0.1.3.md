## 新增

- **谱面历史**。自动保存解析链接、编辑内容和 128×128 JPG 封面缩略图。支持重新打开继续编辑、单条删除、多选和全选删除。
- **封面裁切**。解析页新增 1:1 裁切工具，可调整自动取得的原图。手动替换图片时会先打开裁切弹窗，点「应用」后更新封面。
- **曲尾留白**。试听和导出的音频都可以在末尾追加静音，默认 2 秒。
- **YouTube 登录指引**。登录页提供 Get cookies.txt LOCALLY 扩展链接，并说明如何导出和导入 Netscape 格式的 Cookie。

## 调整与修复

- **偏移设置**。前后偏移的默认值放在设置的同一行，各自支持秒或拍。解析页的前偏移按拍显示和编辑，括号里的时长变化保留秒数，后偏移按秒编辑。
- **默认预览区间**。普通歌曲从 0 秒到曲尾。网易云有有效副歌数据时，使用副歌的起止时间，出点最多到歌曲末尾。
- **拖动预览标记**。播放时按住入点或出点，试听会越过原出点并继续到曲终。
- **许可文件**。Tauri Vue Template 的 MIT 声明移到 README，安装包继续附带该声明。
